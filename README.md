# Tuboleta – prototipo académico

Prototipo web que simula una boletería de eventos para grabar un video tutorial.
**No es el sitio oficial de TuBoleta.** No tiene backend, autenticación ni pagos reales.

## Cómo correrlo

```bash
npm install
npm run dev
```

Abre http://localhost:3000.

## Stack

Next.js (App Router) + TypeScript + Tailwind CSS. Sin librerías de UI.
